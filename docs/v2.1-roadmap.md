# Fondeks v2.1 — Win the "Choose" stage

**Phase 1 of the decoupling strategy** (*Decoupling the Fund Investor's Value
Chain*). The goal of v2.1 is one sentence: move Fondeks from a better TEFAS
table to the independent tool that answers **"am I in the right fund?"** — the
Choose stage incumbents will not fix because the honest answer often points away
from their own funds.

Phase 2 (multi-bank portfolio / "Hold") and the full programmatic SEO batch are
explicitly **out of scope** for this release; see [Deferred](#deferred).

---

## What ships in v2.1 (client)

All of the below is live in `fondeks-client`. Market figures that need the API
(`api.fondeks.com`) degrade to **"Bilinmiyor"** rather than a fabricated number,
so the UI shipped ahead of the backend — the backend work that lights these up
is in [`v2.1-backend-requirements.md`](./v2.1-backend-requirements.md).

### 1. Decision metrics on the fund page — `DecisionPanel`
`src/components/fund-detail/DecisionPanel.tsx`

A "Karar Paneli" above the chart that leads with a plain-Turkish **verdict** and
four figures a bank app won't line up:

| Figure | Source | Fallback |
|---|---|---|
| Kategori sıralaması (percentile) | API `categoryPercentile` | Bilinmiyor |
| Reel getiri (TÜFE sonrası) | API `realReturn.y1` | Bilinmiyor |
| Stopaj sonrası net | API `netReturn.y1`, else derived from the stated stopaj rate | Bilinmiyor |
| Toplam gider oranı (TER) | API `ter` | Bilinmiyor |
| Çok-yıllı tutarlılık | API `consistency` | gizli |

The verdict names the trap the old homepage fell into: a fund up today but down
over the year is called out as exactly that. **Sub-year funds** are judged on
their return *since inception* (computed from the price series), never reported
as "0% in a year" they have not lived.

### 2. Goal-based homepage — `GoalGrid`
`src/components/funds/GoalGrid.tsx`, wired into `src/app/(app)/page.tsx`

The screen now leads with **"Ne yapmak istiyorsun?"** — five goal cards (nakit,
altın, tahvil, dengeli, uzun-vadeli hisse) that route to ranked category pages —
instead of the day's top mover. This is the direct fix for diagnosis #1 (the
homepage optimized for speculation, not the investor's real job).

### 3. Goal / comparison pages — `/kategori/[slug]`
`src/app/(app)/kategori/[slug]/page.tsx`, taxonomy in `src/lib/fondeks/goals.ts`

Five evergreen, indexable landing pages ("en iyi altın fonları", …): an honest
intro, the category leader shown with the full decision panel, the ranked list,
and a one-click "compare the top 3" CTA. Added to the sitemap at priority 0.85.
These are the **first comparison pages** and the seed of the SEO moat.

### 4. Compare board upgrades
`src/lib/fondeks/compare.ts`, `src/components/fund-detail/CompareTrackBar.tsx`

The compare table now carries the Choose rows (stopaj sonrası net, reel getiri,
TER, kategori dilimi). A **"Kararını ver, takibe al"** bar under the board turns
a comparison into a decision — the Choose→Hold coupling point.

### 5. Compare-to-track instrumentation (the north star)
`src/lib/analytics/` (`compareTrack.ts`, events in `types.ts`)

New GA4 events: `goal_entry_click`, `category_page_viewed`, and the north-star
**`compare_to_track`** — fired when a fund the user had compared is added to
their tracking list. A per-session memory of which funds were compared lets the
watch action report whether the add followed a comparison.

## Costs cut (the decoupling test)

Every item above removes money, time or effort cost — Teixeira's test:

- **Money** — TER, after-stopaj and real return expose the fees and tax drag a
  nominal number hides.
- **Time** — goal pages answer "best fund for X" in one screen instead of
  filtering 2,060 rows.
- **Effort** — the plain-Turkish verdict interprets the numbers so the investor
  doesn't have to.

---

## KPIs

North star: **compare-to-track conversion** — share of users who add a fund to
tracking after comparing it (`compare_to_track` with `compared: true` over
`compare_fund_added` sessions). Supporting: `category_page_viewed` →
`goal_entry_click` funnel, organic sessions to `/kategori/*`.

Targets are set once the baseline lands — instrumentation is live, so the
baseline can be read now.

---

## Dependencies & gate

v2.1 ships client-complete today. It reaches **full value** when the backend
fills the fields in [`v2.1-backend-requirements.md`](./v2.1-backend-requirements.md):
TER, net/real return, category percentile, consistency, allocation as-of date,
and a sub-year return for list contexts. Until then the new surfaces render with
honest "Bilinmiyor" placeholders — no regression, no fabricated figures.

**Legal gate (strategy guardrail):** the decision panel and goal pages are
framed as filters, rankings and education, never "senin için al". A legal review
of the advisory boundary (SPK yatırım danışmanlığı) should precede any "for you"
framing in a later release.
